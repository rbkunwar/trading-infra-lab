# Incidents

Every real problem gets a blameless postmortem using this template:

```
# INC-XXX: title
Status · Node · Detected · Resolved
## Summary        what happened, in 2–3 lines
## Impact         who/what was affected
## Timeline       timestamps (with time zone)
## Evidence       real command output
## Root cause     why it happened (keep asking "why?")
## Resolution     what fixed it
## Action items   what we change so it can't happen again
## Lessons        what I learned
```
